# Global Income Group Analysis Dashboard

## Project Overview

In this project, I analyzed a global country classification dataset to understand how countries are distributed across different income groups and regions. The goal was to identify global economic patterns and visualize the relationship between regions and income classifications through an interactive Excel dashboard.

To complete the project, I used Microsoft Excel for data cleaning, analysis, and dashboard development. The dashboard provides a clear overview of income group distribution and regional economic composition.

## Data Preparation and Analysis Process

### Data Review

* Reviewed the dataset to understand its structure and key fields.
* Examined country classifications, regions, and income groups.
* Identified the most relevant fields for analysis and reporting.

### Data Cleaning

* Checked for missing, duplicate, and inconsistent values.
* Removed aggregate and non-country records to ensure accurate country-level analysis.
* Organized the dataset for easier reporting and visualization.

### Feature Selection

I focused on the following fields:

* Country Name
* Country Code
* Region
* Income Group

These fields were used to analyze income distribution across different regions of the world.

### Dashboard Development

* Created Pivot Tables to summarize countries by income group and region.
* Built KPI cards to provide a quick overview of:

  * Total Countries
  * Total Regions
  * Total Income Groups
* Added slicers to allow users to interactively filter and explore the data.

## Data Visualizations

To highlight key patterns in the dataset, I created:

### Income Group Distribution

* A horizontal bar chart showing the number of countries in each income group.

### Regional Income Composition

* A stacked bar chart comparing income group distribution across regions.

### Income Group Share

* A donut chart displaying the percentage share of each income group.

These visualizations provide both a high-level overview and a detailed regional perspective of global income classifications.

## Key Findings

* Countries are not evenly distributed across income groups.
* Income classifications vary significantly between regions.
* Some regions have a larger concentration of high-income countries, while others are dominated by middle-income and lower-income countries.
* Interactive filters make it easy to compare income group distributions across different regions.
